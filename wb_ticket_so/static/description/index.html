Helpdesk Ticket to Sales Order

Streamline your sales process by directly connecting Support Tickets with Sales Orders. This module allows users to create new sales orders or link existing ones directly from the helpdesk ticket, ensuring seamless traceability and better collaboration between support and sales teams.

Features

Create Sales Orders directly from Helpdesk Tickets with a single click.
Syncs all SO chatter messages to the linked Ticket for complete visibility.
Link existing Sales Orders to Tickets using an intuitive wizard interface.
Maintains full audit trail of SO lifecycle events (create, link, cancel, delete).
Smart button displays SO count with one-click access to all linked orders.
Pre-populates SO form with Ticket data for faster order creation.
Auto-transition Ticket to "SO Generated" stage when SO is created or linked.
Works seamlessly with existing Helpdesk and Sales workflows.

1) Install the Module
Go to the Odoo Apps menu and install the module.



2) Open a Helpdesk Ticket. You will see two new buttons in the header: Create Sales Order and Link Existing SO.



3) Click Create Sales Order to instantly generate a new SO that is automatically linked to the ticket. The specific ticket and customer details are pre-filled.



4) Alternatively, use the Link Existing SO wizard to search for and attach one or more existing sales orders to the ticket.



5) Once an SO is created or linked, the Ticket automatically moves to the SO Generated stage, notifying the team that sales process is in progress.



6) View the count of all linked Sales Orders via the Smart Button on the top right of the ticket form. Click it to view the full list.



7) Full History & Logs: All actions, including SO creation, linking, and status changes, are automatically recorded in the chatter for full traceability.



Can I link multiple Sales Orders to a single Ticket?

Yes, you can link as many Sales Orders as needed to a single Helpdesk Ticket. The smart button will show the total count.

Does the module automatically communicate directly with the customer?

No, the module syncs internal notes and messages between the SO and the Ticket for internal team visibility. Explicit messages to customers must still be sent from the ticket.

What happens if I delete a linked Sales Order?

The module logs the deletion event on the linked Helpdesk Ticket's chatter, ensuring you have a record that an SO was removed.
